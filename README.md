# 股票健檢

輸入上市股票代號,依公開資料自動計算技術面、估值、基本面,給出 5 級評等(強力買進 / 買進 / 持有 / 減碼 / 賣出)與分批進場區間。

- 網頁:純前端(`index.html`),手機與電腦都能開;價格與本益比由瀏覽器直接讀取臺灣證券交易所公開資料。
- 基本面:`scripts/build_fundamentals.py` 由 GitHub Actions 每個交易日下載證交所 OpenAPI,存成 `data/fundamentals.json`。
- 不含持股、不含資金配置。
- 目前只支援上市股票。
- 「下載 PDF 報告」:按鈕會開啟列印視窗,選「另存為 PDF」。

## 免責聲明
本工具為依公開資料以固定規則自動計算的研究輔助,評等、進場區間與估值皆為量化推算,不是投資建議,也不保證獲利。投資有風險,請自行判斷並承擔結果。

## 評等規則
綜合分數 = 技術面 25% + 估值 35% + 基本面 40%(各項範圍 −2 至 +2)。≥1.3 強力買進、≥0.5 買進、−0.35 至 0.5 持有、−1 至 −0.35 減碼、其餘賣出。
